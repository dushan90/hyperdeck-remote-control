# HyperDeck Remote Control

A web-based remote control application for Blackmagic Design HyperDeck devices.

![Control Interface] (https://github.com/dushan90/hyperdeck-remote-control/blob/master/Screenshot.png)

## Project Summary

This is a complete remote control application for Blackmagic Design HyperDeck devices that allows control over LAN. The application provides a user-friendly interface for controlling HyperDeck devices with features such as:

- Web-based control interface
- Executable Windows application
- Setup file for easy installation

## Files

The project includes all necessary files for installation and use.

## Installation

Run the setup file `HyperDeck_Remote_Control_Setup.exe` to install the application on a Windows system.

## Usage

1. Install the application using the setup file
2. Launch the HyperDeck Remote Control
3. Connect to your HyperDeck device over LAN
4. Control your device through the intuitive interface
